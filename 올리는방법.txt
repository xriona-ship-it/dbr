[DBR커뮤니케이션 홈페이지 올리는 방법 - 웹호스팅(카페24 등)]

1. config.php 를 메모장으로 열어 비밀번호와 알림 이메일을 바꿉니다.
2. index.html 에서 010-0000-0000, 대표 ○○○, 사업자등록번호를 실제 정보로 바꿉니다.
3. FileZilla로 FTP 접속 → www (또는 public_html) 폴더에 전체 파일을 올립니다.
   index.html / contact.php / admin.php / config.php / data 폴더(.htaccess 포함)
4. data 폴더 우클릭 → 파일 권한 → 707 로 설정합니다.
5. 도메인으로 접속해서 상담 폼을 한 번 테스트합니다.
6. 접수 확인: 도메인/admin.php  (config.php 비밀번호로 로그인)
